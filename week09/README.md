공통 경로는 모델 다운로드·유료 API·GPU 없이 실행한다. MOCK은 고정 문장과 대기를 사용한 시뮬레이터다. 실제 LLM 학습·추론 품질·GPU 처리량을 검증한 결과로 해석하지 않는다. Ollama는 선택 연결이며 실제 모델의 설치·속도·품질은 사용자 기기에서 별도로 확인한다.

새로운 과제 제출 기한이나 평가 배점을 이 초안에서 만들지 않는다. 실행 증거는 기말 프로젝트의 구현 포트폴리오에 누적하고, 제출 방식·기한은 소속별 공지를 따른다.
