# 프로젝트 기획서 작성 양식

- [`08_project_proposal_word_template.docx`](08_project_proposal_word_template.docx): 편집 가능한 Word 2Pager 양식. 같은 내용의 [인쇄용 PDF](../../output/pdf/08_project_proposal_word_template.pdf)도 제공한다.
- [`08_project_proposal_ppt_template.pptx`](08_project_proposal_ppt_template.pptx): 편집 가능한 6장 요약 양식. 제목·문제·사용 흐름·기술·평가·제출 일정 순서다.
- 별도의 [독립형 2Pager HTML](../../curriculum/2026-2/web/project-proposal-2pager.html)과 [PRD HTML](../../curriculum/2026-2/web/project-prd.html)도 선택할 수 있다.

7주차 10월 16일에 초안 0.1을 먼저 제출해 교수 피드백을 받고, 8주차 10월 23일에는 수정본 0.2를 제출한다. 아주대AI대학원 팀은 LMS, 다른 학교의 개인 프로젝트는 공지된 담당 교수 이메일을 사용한다. PPT·Word·Word 기반 PDF·HTML 중 적합한 형식을 선택하고, 한글(HWP) 파일은 제외한다. 정확한 제출 시각과 이메일은 소속별 공지를 확인한다.

양식의 대괄호는 작성용 안내다. 제출 전 실제 내용으로 바꾸고, 검증하지 않은 성능·시장 수치를 사실처럼 적지 않는다. 출력 PDF는 양식 미리보기이며 Word 파일을 작성한 뒤 새 PDF로 인쇄·저장한다.
