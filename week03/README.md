## 3분 실행

VS Code에서 저장소 루트를 열고 **Terminal → Run Task → Week 03: Run EVAL/03**을 선택한다. 또는 macOS/Linux 터미널에서 실행한다.

```bash
.venv/bin/python -m uvicorn eval03.main:app --app-dir week03/lab --host 127.0.0.1 --port 8003
```

브라우저에서 <http://127.0.0.1:8003>을 연다. `두 버전 평가 실행` → 실패 행 선택 → `보류` 근거 작성 → JSON 내보내기 순서로 진행한다. 서버는 `Ctrl+C`로 종료한다.

- 1주차 8000번, 2주차 8002번과 함께 실행할 수 있다.
- Demo는 고정 응답을 재생한다. 통과율은 실제 LLM 성능이나 프롬프트 개선 효과가 아니다.
- 코드와 화면에는 합성 회의 발췌만 있다. 실제 회의록, 학생 개인정보, API 키를 넣지 않는다.
- 8주차는 실시간 수업 없이 온라인 기획서 제출·평가, 16주차는 실시간 온라인 프로젝트 발표로 진행한다.
