## 권장 복습 순서

1. [학생용 3주차 PDF](../../output/pdf/03_week3_prompt_evaluation_error_analysis.pdf)에서 평가 기준과 실습 순서를 확인한다.
2. 강의 영상에서 dev/test 분리, M02·M03 오류 해석, 후보 결정 기록을 본다.
3. [EVAL/03 실습 안내](../lab/README.md)와 [VS Code 실행 가이드](../VS_CODE_GUIDE.md)를 따라 평가·결정·JSON 내보내기를 재현한다.
4. 영상의 안내와 현재 PDF가 다르면 현재 `main` 브랜치의 PDF·실습 코드·수업 공지를 우선한다.

Google Drive 파일의 재생·다운로드 가능 여부는 해당 파일의 공유 권한을 따른다. 수강생 과제, 실제 회의 기록, API 키는 공개 GitHub나 복습 자료에 올리지 않는다.
