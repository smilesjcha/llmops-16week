# Week 01 공개용 기록 비식별 편집 로그

이 문서는 공개 저장소에 연결하는 1주차 강의 기록의 개인정보 처리 기준과 검증 범위를 설명한다. GitHub 저장소는 **Public** 상태를 유지한다.

## 공개 기준

- 교수자 차성재의 이름·얼굴·음성·공개 프로필은 유지 가능
- 수강생 등 제3자의 이름·아이디·얼굴·프로필·소속은 비노출
- 비공개 메시지와 개인 프로젝트를 특정할 수 있는 내용은 비노출
- 특정 학교별 제출·배포 경로는 통합 강좌 공개본에서 비노출
- 1주차 원본 녹화·음성·채팅 내용이 남아 있는 Drive URL과 제한 백업 파일 ID는 공개 저장소에 기록하지 않음

## 영상·음성 편집

| 항목 | 공개용 처리 |
|---|---|
| 시작부 | 제3자 단독 화면이 끝난 원본 00:00:16부터 시작 |
| 참가자 패널 | 원본 2056×1330 기준 우측 520px를 전 구간 불투명 패널로 대체 |
| 기관별 안내 | 전사로 확인한 4개 구간을 공개용 편집 카드와 무음으로 대체 |
| 후반 질의응답 | 개인 질문과 연락처 안내 전인 원본 01:51:18에서 종료 |
| 공개용 음성 | 공개용 영상과 동일한 시작·무음·종료 편집을 적용 |
| Drive 배포 영상 | 1280×828 H.264, 48 kHz AAC mono, 01:51:02, 88.8 MB |

블러는 글자나 얼굴의 형태가 남을 수 있어 사용하지 않았다. 참가자 패널은 복원이 불가능한 불투명 면으로 완전히 덮었다.

## 채팅 편집

- 메시지별 수강생 식별자를 제거하고 주제 단위 요약으로 전환
- 정확한 메시지 시각 제거
- 비공개 대화 본문 삭제
- 개인 프로젝트의 도메인·데이터·구현 세부 내용 일반화
- 단순 인사처럼 학습 맥락에 필요하지 않은 메시지 제외
- 교수자 연락처는 공개 가능 여부와 별개로 데이터 최소화 원칙에 따라 생략

## 검증 방법

- 영상 전체를 30초 간격으로 프레임 추출하여 참가자 패널 위치 점검
- 시작부를 1초 간격으로 확인하여 제3자 단독 화면 종료 시점 점검
- 전체 음성을 자동 전사하고 위험 후보를 고정밀 모델로 재전사하여 편집 구간 확정
- 편집본의 시작·무음 구간 전후·종료 프레임과 미디어 길이 재검증
- Git 추적 파일에서 원본 Drive URL·파일 ID와 수강생 식별정보 검색
- 공개 링크 3개의 `링크가 있는 모든 사용자 · 보기` 권한과 비로그인 HTTP 200 응답 확인

자동 전사는 누락 가능성이 있으므로 공개본은 음성 전사뿐 아니라 화면 샘플링과 채팅 원문 검토를 함께 사용해 보수적으로 편집했다.
