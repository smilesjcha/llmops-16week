## 최신 운영 기준

비식별 채팅 내역은 수업 중 질문과 대화의 흐름을 요약한 기록이며 확정 공지 문서가 아니다. 채팅·영상의 표현과 현재 운영안이 다를 때는 학습관리시스템(Learning Management System, LMS)의 최신 공지, [현행 운영 커리큘럼](../../curriculum/2026-2/00_운영_커리큘럼.md), 학생용 PDF 순서로 우선한다.

현재 운영 기준은 중간고사 없이 8주차에 기말 프로젝트 기획서 0.1을 온라인으로 제출·평가하고, 16주차에 프로젝트 발표를 실시간 온라인으로 진행하는 방식이다.

## 개인정보와 재배포

공개용 영상은 시작부의 수강생 단독 화면과 참가자 패널을 제거했다. 특정 학교·제출 경로 안내 구간은 편집 카드와 무음으로 대체했고, 개인 프로젝트 질문이 시작되기 전에 종료했다. 공개용 음성에도 같은 시간 편집을 적용했다.

공개용 채팅은 교수자 차성재의 이름과 공개 GitHub 주소만 유지했다. 수강생 이름·아이디·학과·프로필과 정확한 메시지 시각을 제거하고, 비공개 메시지·연락처·개인 프로젝트 세부 내용은 삭제하거나 주제 단위로 요약했다.

비식별본도 강의 복습과 포트폴리오 참고 범위에서 사용하며, 참여자를 추정하거나 원본 정보를 복원하려는 용도로 사용하지 않는다.

세부 편집 범위와 검증 방법은 [공개용 기록 비식별 편집 로그](PRIVACY_EDIT_LOG.md)에서 확인한다.
