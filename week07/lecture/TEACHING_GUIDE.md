## DPO 설명의 순서

1. 24–25쪽에서 같은 질문의 답변을 선택하고 이유를 말한다. chosen을 절대적인 진실로 소개하지 않는다.
2. 35쪽은 원 논문 Figure 1이다. PPO 기반 RLHF의 보상 모델·샘플링 경로와 기본 DPO를 비교한다. 비용 0이나 보편적 성능 우위를 주장하지 않는다.
3. 37–41쪽에서 policy의 선호 차이 3에서 reference의 차이 0을 뺀다. 네 로그확률은 가상 값이며 Judge 점수가 아니다.
4. 38–39쪽은 답변 토큰의 자연로그 합이다. 단순 길이 평균을 섞으면 기본 목적과 달라질 수 있다.
5. 42–46쪽은 고정 margin의 손실·β 효과다. 이 곡선으로 실제 학습의 최적 β를 결정하지 않는다.
6. 47–51쪽은 질문 하나·고정 답변 둘의 Bernoulli 정책이다. θ 한 개를 80회 갱신하며 언어 모델 학습이나 새 질문의 일반화 검증이 아니다.

## 비교 평가와 실습

56–58쪽의 12건은 직접 작성한 플래그 조합이며 실제 모델·사람 평가 결과가 아니다. 수업용 규칙은 candidate 4, baseline 4, tie 3, review 1이다. 형식 9→11건과 근거 10→9건을 함께 읽고, 평균·승률 하나에 개선과 회귀를 섞지 않는다. 실제 보류 입력·응답 원문·비용·표본 수·사람 검토가 추가로 필요하다.

63쪽과 `week07/lab/README.md`의 연결표를 사용한다. 05는 다른 노트북 없이 독립 실행 가능하다. 원본 .ipynb에는 실행 출력·학생 원문을 넣지 않으며 검증 실행본은 로컬 `output/validation/`에 남긴다.

## 기획서 리뷰

첫 문단은 사용자·문제·제안·범위부터 시작한다. 제작 과정은 필요한 경우 부록으로 이동한다. 75쪽처럼 기능 요구사항을 확인 방법·실패 처리에 연결한다. 76쪽의 글쓰기 서비스는 문단 구조·주장과 근거·유창성·이해도를 별도 기준으로 검토하며 학생 성적 자동 결정은 제외한다.

사업 가치·사용 경험·개발·평가 관점의 질문을 나누고 교수 피드백의 채택·보류·반박과 추가 근거를 기록한다. 프로토타입은 실제 LLM·고정 응답·수동 처리 범위를 명시한다.

수정본 마감은 **2026-10-22(목) 23:59 한국시간**이다. 10월 23일은 시험·실시간 수업 없이 제출물 평가다. 아주대AI대학원은 2–4인 자율 팀·LMS 제출을 기본으로, 군산대·국립창원대 등은 개인 진행·공지 이메일 제출이 가능하다. 개인 예외는 교수 승인 확인이 필요하다. 명단·메일·연락처는 공개 GitHub에 포함하지 않는다.
