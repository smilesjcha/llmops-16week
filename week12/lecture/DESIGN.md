# 12주차 HTML 강의안 제작 규칙

- 검정·흰색·네이비·파랑. 상태마다 새로운 색을 부여하지 않고 이유를 문자로 구분.
- 1440×810, 장표 하나당 PDF 한 페이지. 본문 23–28px 중심, 출처 16px. 긴 숫자·약어·도식 내부 텍스트 별도 확인.
- 비교 표, 사용자 단위 그림, 분수, 분기 아키텍처, 원문 이미지, 실제 화면, 막대·신뢰구간, 코드·출력 등 내용에 맞는 구조 선택.
- 외부 복잡 도식은 상위 구조 설명과 원문 확대용. 작은 세부 글씨를 강의 중 필수 읽기 대상으로 삼지 않음.
- SVG 흐름은 단계별 강조, 표본 수는 조작형 예시. 모션 감소 환경 지원. 인쇄에는 전체 구조와 기본 예시 표시.
- 64쪽 모두 7종 설명 노트. 교수 창은 현재/다음 미리보기·동기화·글씨 크기·드래그 비율·저장 기능 제공.
- 학생 화면 공유는 강의안 창 하나만 선택. 발표자 모드에서는 학생 창의 노트 조작을 숨김.
- 소스: `scripts/week12_content.py` / 빌드: `scripts/build_week12_html.py`. 생성 HTML 직접 수정 대신 소스 수정 후 재생성.
- 검증: 모든 장표 영역 검사, 390/768/1024px 가로 넘침, 실제 브라우저/로컬 파일 발표자 동기화, PDF 전체 렌더 확인.
