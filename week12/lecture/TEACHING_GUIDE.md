## 학생에게 풀어서 설명할 용어

| 용어 | 풀어 쓰기·의미 |
|---|---|
| A/B 테스트 | 동시기에 배정한 두 집단의 변경 효과 비교 |
| API | Application Programming Interface · 프로그램 사이의 요청·응답 계약 |
| SRM | Sample Ratio Mismatch · 기대 배정 비율과 관측 사용자 비율의 불일치 |
| p95 | 95th percentile · 응답 시간의 95번째 백분위수 |
| %p | percentage point · 두 비율의 절대 차이 |
| CI | Confidence Interval · 신뢰구간 |
| MDE | Minimum Detectable Effect · 탐지 목표로 설계한 최소 효과 크기 |
| Guardrail | 성과가 좋아도 넘지 않아야 할 운영 보호 기준 |
| Trace / Span | 한 요청의 전체 실행 기록 / 그 안의 작업 구간 |
| Canary | 일부 트래픽부터 적용하는 배포 방식. 자체로 무작위 효과 검정은 아님 |
| HOLD / REVIEW | 위험 때문에 보류 / 자동 조건 통과 후 사람 검토 대기 |

수업의 14일·각 1000명·3%p·p95 1800ms는 교육 사례의 계약입니다. 산업의 공통 정답이 아닙니다. 실제 계획에서는 기준선·탐지 목표·검정력·요일·결과 지연을 고려합니다.
