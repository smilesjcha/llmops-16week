1. 미션 · 새 답변을 시험해도 될까?

교환 정책 질문과 실시간 재고 질문, 총 2개를 두 프롬프트로 실행하고 Langfuse의 Trace와 Scores를 근거로 개선안을 작성합니다. B가 더 좋아져야 하는 과제가 아닙니다. 잘못된 응답·평가자의 오판·지연을 발견하고 근거로 설명하는 것이 목표입니다.

  1. 실제 응답 4건 — 같은 질문을 A baseline, B grounded에 각각 입력합니다. 모델·검색기는 같고 프롬프트만 다릅니다. 답변 생성 4회 + 모델 평가 4회, 총 8번의 Ollama 호출입니다.
  2. 흐름과 평가 확인 — 검색 근거 → 생성 입력·출력 → 코드 검사 → 모델 평가를 확인하고 개별 생성 시간·점수를 비교합니다.
  3. 사람 검토와 판단 — B의 재고 답변을 직접 읽고 사람 검토 점수와 이유를 기록합니다. 보류 또는 추가 검토 판단과 다음 변경 하나를 설명합니다.
  4. 사용자 A/B 계획 — 고정 배정을 확인하고 대상·지표와 분모·보호 기준·기간·중단 규칙을 설계합니다. 실제 사용자 모집이나 온라인 실험 수행은 요구하지 않습니다.
판단 메모 1–2쪽(PDF 또는 HTML) + 근거 화면 2장을 제출합니다. 캡처는 메모 안이나 별도 파일로 넣어도 됩니다. 네 요청으로 일반 정확도·p95·사용자 개선을 입증했다고 쓰지 않습니다.

2. VS Code 실행 순서

Python 3.11의 기존 .venv 커널을 선택합니다. Docker Desktop과 Ollama를 실행하고 저장소 루트의 터미널에서 아래를 진행합니다. 기존 환경은 재사용합니다.

python -m pip install -r requirements/week12-langfuse.txt
python week11/lab/langfuse/init_env.py
ollama pull qwen2.5:1.5b-instruct
docker compose -f week11/lab/langfuse/compose.yaml up -d --wait --wait-timeout 300

내 PC의 Langfuse에서 week11/lab/langfuse/.env의 로그인 계정으로 접속합니다. 첫 설치의 다운로드 시간은 별도입니다. 최초 설치·메모리 요구·문제 해결

코드 셀실행확인 결과
1–2연결·비교 조건모델·세션 ID, 질문·응답 계약
3–4A/B 실제 응답질문 2개 × 버전 2개의 Trace 링크
5서버 저장·비교표요청별 부모 1개 + 하위 작업 4개, Scores·지연
6사람 검토REVIEW·COMMENT 직접 입력, human_review 저장
7고정 배정·계획같은 가상 ID에 같은 버전, 본인 계획 5항목
8증거 저장로컬 evidence.json·comparison.csv

코드 셀은 실행 횟수 [1], [2]가 아니라 코드 셀만 센 순서입니다. 별도 API 서버·Prometheus 설치는 추가로 요구하지 않습니다. 9주차의 요청·응답 계약은 Ollama HTTP 호출과 JSON 필드에서 확인합니다.

3. Langfuse에서 확인할 두 화면

  1. Trace 트리와 입출력 — 셀 5의 B Q24a 링크 → 01-retrieval Output → 02-ollama-answer Input/Output. 근거 없는 재고 단정이나 기권 필드와 문장의 불일치를 확인합니다. 화면 1장 캡처.
  2. Scores와 비교 근거 — 같은 요청의 Scores → 코드 검사·llm_groundedness·직접 작성한 human_review와 이유 비교. Scores 또는 A/B 비교표 화면 1장 캡처하고 메모에 평가 종류의 차이를 설명합니다.

Trace는 요청 전체, Span/Observation은 내부 작업, Generation은 모델 호출 기록입니다. Score는 특정 기준의 평가값입니다. 코드 통과는 의미 정확도 100%가 아니며 작은 모델의 자기 평가도 독립된 정답이 아닙니다. 공식 개념 · Scores 기록 방식

저장은 비동기이므로 셀 5·6의 재조회 후 새로고침합니다. w12-mission 세션으로 이번 실행을 찾습니다. 환경 이름 week11-local은 기존 환경 재사용에 따른 정상 표시입니다. localhost 링크는 교수 PC에서 열리지 않으므로 캡처를 제출하세요.
