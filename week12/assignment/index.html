2. 제공 사례와 데이터

가상 쇼핑 상담에서 A는 짧은 답변, B는 ‘조건·비용·다음 행동’ 구성입니다. 교수 작성 합성 사용자 2400명의 14일 종료 데이터를 분석합니다. 실제 고객이나 실제 모델의 제품 성과가 아닙니다.

항목AB / 차이
사용자1196명1204명
해결 확인율55.02%64.04%
B − A 절대 차이—+9.02%p
차이의 95% 구간—[5.10, 12.91]%p
p95 응답 시간924ms2868ms
사전 운영 상한각 버전 p95 ≤ 1800ms

해결 확인율 분모는 피드백 응답자만이 아니라 실험에 진입한 모든 사용자입니다. 응답 없음·실패도 포함하며 사용자별 첫 요청을 분석합니다. p95는 요청 시간의 95번째 백분위수입니다.

판단을 막힐 때 참고할 힌트

HOLD는 실습 실패가 아닙니다. 성과의 개선 근거가 있어도 운영 상한을 넘었으므로 보류가 타당합니다. 출력 길이 같은 원인 하나를 개선하고, 정책 정확성·필수 정보 누락을 오프라인에서 재검증한 뒤 새 실험을 설계할 수 있습니다. 기존 결과를 통과시키려고 상한을 높이지 않습니다.

4. 확인 기준

  • 근거의 정확성: 사용자 수·분모·%와 %p·지연 단위의 구분
  • 판단의 일관성: 좋은 지표와 운영 위험을 함께 고려한 결론
  • 다음 행동의 구체성: 변경 하나와 품질 재검증 방법
  • 설명의 정직함: 합성 데이터, 작은 모델, 짧은 관찰의 한계 구분

복잡한 구현이나 화려한 디자인보다 근거를 설명하는 능력을 봅니다. 생성형 AI의 도움을 받았다면 사용 범위와 본인이 검증한 부분을 한 줄로 적어 주세요.
