# 학생용 주차별 PDF 강의자료

학생은 매주 이 폴더의 PDF를 강의안 기준본으로 사용한다. 현재 강의안은 특정 대학에 한정하지 않는 대학생·대학원생 대상 통합 LLMOps 강좌 기준이다. `AS-IS 2025 2nd semester` 폴더는 이전 학기 참고자료이며, 현재 수업 자료가 아니다.

> 현재 저장소는 공개(Public)다. 공개 복습 자료는 교수자 공개 정보와 개인정보 비식별 처리를 마친 사본만 연결한다.

## 확인 순서

1. [LLMOps 16주 저장소](https://github.com/smilesjcha/llmops-16week) 접속
2. `output` → `pdf` 폴더 이동
3. 해당 주차 번호로 시작하는 PDF 열기
4. 수업 직전 `main` 브랜치의 최신 파일인지 확인

수정본은 같은 경로에 업데이트하며, 변경 이력은 GitHub 커밋에서 확인할 수 있다. 발표용 PowerPoint와 실습 코드는 각 `weekNN` 폴더에 두지만, 학생이 읽을 강의안의 기준은 이 폴더의 PDF다.

## 주차별 강의안

| 주차 | 수업일 | 주제 | PDF | 진행 방식 | 복습 자료 |
|---:|---:|---|---|---|---|
| 01 | 2026.09.04 | LLM 서비스 운영의 기본 | [01주차 강의안 열기](01_week1_llmops_kickoff.pdf) | 실시간 온라인 | [영상·음성·채팅](../../week01/resources/README.md) |
| 02 | 2026.09.11 | 프롬프트 설계와 버전 관리 | [02주차 강의안 열기](02_week2_prompt_design_versioning.pdf) | 실시간 온라인 | [실습·실행 가이드](../../week02/README.md) |
| 03 | 2026.09.18 | 프롬프트 평가와 오류 분류 | [03주차 강의안 열기](03_week3_prompt_evaluation_error_analysis.pdf) | 실시간 온라인 | [EVAL/03 실습·실행 가이드](../../week03/README.md) |

2주차 강의안은 72쪽으로, 1–60쪽은 2시간 본 수업용이고 61–72쪽은 심화 참고용이다. 실습은 [VS Code 실행 가이드](../../week02/VS_CODE_GUIDE.md)를 따라 진행한다.

3주차 강의안도 72쪽으로, 1–60쪽은 100분 본 수업용이고 61–72쪽은 루브릭·오류 분류·코드 구조 참고용이다. 실습은 [3주차 VS Code 실행 가이드](../../week03/VS_CODE_GUIDE.md)에서 `EVAL/03`을 실행한다.

2주차부터 격주 과제를 진행하며 출제 후 일주일 이내에 제출한다. [과제 01](../../week02/ASSIGNMENT_01.md)은 **2026년 9월 18일 이내**에 JSON 실험 보고서와 짧은 분석 PDF를 제출한다. 마감 시각은 별도 공지를 확인한다. [소속별 제출 경로](../../week02/ASSIGNMENT_01.md#제출-경로와-일정)는 온라인 학습관리시스템(Learning Management System, LMS) 또는 이메일이며, 공개 GitHub는 과제 제출 경로가 아니다.

## 파일 위치 규칙

- 학생용 PDF: `output/pdf/`
- 발표용 PowerPoint: `weekNN/lecture/`
- 실습 안내와 코드: `weekNN/README.md`, `weekNN/lab/`
- 개인정보 비식별 강의영상·음성·채팅 기록: `weekNN/resources/`
- 학기 운영 일정: `curriculum/2026-2/`

공휴일 주차는 휴강이 아니라 녹화 영상 업로드로 대체한다. 8주차는 실시간 수업 없이 기말 프로젝트 기획서를 온라인으로 제출·평가하며, 16주차 프로젝트 발표는 실시간 온라인으로 진행한다.
