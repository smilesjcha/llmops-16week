# 6주차 확장 강의안 · 76장

6주차 기술 내용의 배경·구조·실행 예시를 다루는 복습용 자료다. 10월 9일 휴일에 새 강의를 개설하거나 과제를 추가한 것이 아니다. 실제 기술 수업은 10월 16일 6–7주차 통합 강의와 연결한다.

## 장표 구성

| 구간 | 내용 | 설명·활동 |
|---|---|---|
| 01–12 | 배경과 기술 선택 | 최신 정책 오류와 반복 형식 오류의 대안 비교 |
| 13–26 | SFT의 손실 | 공식 도식, 다음 토큰 정렬, 정답 확률, 마스킹·잘림 실험 |
| 27–36 | 자료와 검증 | 오류 주입, 문장/사건 분할, 누출, 학습 설정과 일반화 |
| 37–54 | LoRA | 원 논문, 두 계산 경로, 차원·파라미터·rank 오차, 설정·보존 |
| 55–67 | QLoRA | 세 학습 방식 비교, 균등 양자화, NF4, Double Quantization, 메모리 |
| 68–76 | 실습과 평가 | VS Code, 파일 연결, 통합 사례, 비교 조건·회귀·확인 질문 |

100분 자가 복습 예시: 배경 10분, SFT 25분, LoRA 25분, QLoRA 20분, 실습 정리 20분. 코드 예시는 각 개념을 읽으며 실행한다. 4쪽의 시간표와 70쪽의 파일·장표 연결표를 기준으로 필요한 구간을 선택한다.

## 설명 순서

- 18쪽의 예측 위치와 원본 label 위치를 먼저 대조한 뒤 24쪽 코드를 실행한다. 답변 ID는 20·21·22, shift 후 예측 위치는 2·3·4다.
- 20–21쪽은 가상 확률을 자연로그 손실로 바꾼 계산이다. 새 모델의 정확도 개선 성과가 아니다.
- 31–33쪽은 동일 사건의 표현이 분할을 넘는 누출을 다룬다. 7주차 Notebook 01의 의도적인 잘못된 분할을 먼저 확인한다.
- 40–46쪽은 12×8 작은 행렬과 4096×4096 층 하나를 구분한다. 파라미터 개수와 전체 VRAM은 다르다.
- 47쪽에서 SVD 행렬 근사와 실제 데이터 기반 LoRA 학습을 구분한다.
- 58–61쪽은 균등 양자화의 복원 오차 실험이다. NF4 구현이나 실제 모델 품질 측정이 아니다.
- 64–66쪽은 원시 가중치 저장량과 전체 학습 메모리를 분리한다. 가정한 7B의 3.5 GB만으로 GPU 용량을 결정하지 않는다.
- 72–74쪽은 같은 입력·조건에서 비교할 평가 계획이다. 가상의 개선·회귀 시나리오를 실제 실험 결과로 소개하지 않는다.
