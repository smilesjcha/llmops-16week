제안 결론

논증형 글쓰기 학습자를 위한 근거 기반 수정 코치. 글을 대신 완성하거나 자동 성적을 확정하지 않고, 작성자가 자기 글의 주장·근거·구조를 확인하고 수정하도록 지원합니다.

사용자 문제·가설

가설: “잘 썼다”는 총평만으로는 어떤 문장을 고쳐야 하는지 파악하기 어렵습니다. 학습자 인터뷰와 수정 전후 과제로 검증합니다. 아직 확인하지 않은 수요를 시장 사실로 제시하지 않습니다.

검증과 운영

교수자 기준표 → 비식별 예문 → 근거 문장 대조 → 구조화된 출력 검증 → 사람 검토 → 학습자 수정. 형식 검증만으로 내용 타당성을 보장하지 않습니다.

최소 시제품: 기준표 1종·공개/합성 예문 20개·고정 테스트 입력·누락/잘못된 인용 분석. 평가자 간 불일치도 기록합니다. 성적 자동 결정·학생 순위화는 범위에서 제외합니다.

삭제 기능·접근 권한·동의 범위·보관 기간을 정의하고 실제 학생 글의 외부 모델 전송은 사전 승인 없이 하지 않습니다.
