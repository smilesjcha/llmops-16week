수업 중 지연에 대한 대응

기록이 아직 보이지 않는 경우

Notebook의 wait_for_trace가 저장 완료를 확인한 다음 같은 요청을 새로고침합니다. 전송 직후에는 worker 처리 시간이 필요합니다. 반복 실행으로 새 요청을 계속 만들지 않습니다.

모델 호출 또는 Docker가 준비되지 않은 경우

설치 점검은 최대 3분으로 제한하고 교수 화면·실제 비교 결과로 판단 활동을 이어갑니다. 이를 본인의 실시간 실행으로 제출하지 않습니다. 수업 후 준비 안내의 오류 항목을 따라 실행합니다.

이미지·포트·시간 예산

여섯 컨테이너가 실행되므로 기기 여유 메모리가 필요합니다. 이 자료는 Docker VM RAM 약 16GB인 macOS에서 검증했습니다. 3011은 Langfuse, 11434는 Ollama입니다. 실행 시간은 장비마다 달라집니다. 3초 조건은 교육용 기본 예산이며 실험 전에 합의합니다.
