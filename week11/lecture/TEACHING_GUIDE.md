# 11주차 100분 진행안

[교수용 강의 준비 HTML](https://smilesjcha.github.io/llmops-16week/week11/lecture/instructor/)에서 전체 64쪽 요약·페이지별 설명 예시·학생 질문과 09·10번의 코드 셀 18개 안내를 볼 수 있습니다. [한 문장 목차](INSTRUCTOR_OVERVIEW.md)와 [상세 노트](lecture-notes.md)도 제공합니다.

핵심 질문: **실패를 추적하고, 같은 기준으로 변경을 비교한 뒤, 어떤 근거로 배포를 결정할 것인가?**

64쪽을 모두 같은 속도로 설명하지 않습니다. 01–08의 계산 심화는 복습용으로 두고, 실제 요청을 관찰하는 09번과 세 버전을 비교하는 10번에 시간을 배정합니다.

| 시간 | 장표 | 진행과 완료 확인 |

| 10–25분 | 7–27 핵심 발췌 | 문서 버전·데이터 분리·검색과 답변 성공 차이. 01–04 일부 |

## 사전 준비

1. [Docker·VS Code 준비](../lab/langfuse/README.md)의 설치·모델 다운로드·기동을 수업 전에 완료합니다.
2. `http://localhost:3011` 로그인, 09번 첫 셀 인증·모델 확인.
3. 강의안 16쪽 지표 조작과 46·47·51쪽 실제 화면 확대 확인.
4. [파일별 실행 순서](../lab/WALKTHROUGH.md)와 [실제 비교 결과](https://smilesjcha.github.io/llmops-16week/week11/lab/sample/langfuse/)를 함께 엽니다.
5. 설치 문제가 있는 학생은 실제 캡처·검증 결과로 동일한 판단 활동을 먼저 진행하고 환경 복구 후 재현합니다.

## 학생의 판단을 끌어낼 세 장면

- **예측:** “현재 재고가 없다”와 “확인할 수 없다” 중 어떤 표현이 근거에 맞는가? 프롬프트를 강화하면 기권 필드도 맞을까?
- **추적:** 09번의 실제 Input에 재고 정보가 있었는가? 코드 점수와 모델 판정이 서로 어긋나면 무엇을 믿고 추가 확인할까?
- **배포 결정:** 10번 A/B/C에서 어떤 변경이 어떤 실패를 막았는가? 계약 검사 100%만으로 배포할 수 있을까?

두 명씩 60초 동안 예측을 비교한 뒤 실제 화면을 확인합니다. 마지막에는 각자 결론 한 문장·실패 근거 하나·다음 변경 하나를 적습니다. 새 과제 마감·배점을 추가하는 활동은 아닙니다.

## 설명의 경계

- 01–06: 실제 검색·지표 계산. 05의 judge 표는 작성 예시입니다.
- 07–08: 실제 Ollama 생성·평가, 로컬 JSONL.
- 09–10: 실제 SDK 전송, Docker Langfuse 서버 저장·UI 확인. LangSmith는 개념 사례입니다.
- 40쪽은 공식 제품 예시. 46·47·51쪽은 이 수업의 실제 로컬 실행 캡처입니다.
- C의 미지원 기능 경로는 서비스 정책 응답입니다. 생성·모델 평가 호출을 했다고 설명하지 않습니다.
- 기능 유형은 UI 메뉴/API 라우트 입력입니다. 자유 문장 의도 분류·실시간 재고 API는 구현하지 않았습니다.
- 4건의 계약 검사 결과를 정확도 또는 p95 지연으로 소개하지 않습니다. REVIEW는 사람 검토 단계이며 실제 배포가 아닙니다.

질문이 많으면 44–45쪽 준비 구조 설명과 09 코드 셀 2의 최소 SDK 예제를 짧게 읽고, 09 코드 셀 3–5의 전체 요청과 10의 A/B/C 비교 시간을 우선 확보합니다. 아래 번호는 설명 제목의 단계 번호가 아닌 위에서부터 코드 셀만 센 순서입니다. 현재 수업의 정수는 **관찰 → 실패의 평가 데이터화 → 변경 비교 → 필수 조건에 따른 차단 → 사람 검토**입니다.


## 발표 조작과 화면별 시연

- 상단 단계명: 해당 구간 시작으로 이동. 목차에서는 제목·도구 이름 검색.
- 4·5·21·44쪽: ‘흐름 보기’ 또는 F → 관련 노드와 설명을 순서대로 확인. 인쇄 PDF는 전체 도식.
- 46·47·51쪽: 큰 설명을 먼저 안내한 뒤 ‘그림 확대 → 원본 크기’ 또는 실제 Langfuse 링크로 이동.
- [클릭 순서·학생 질문·확인 결과](https://smilesjcha.github.io/llmops-16week/week11/lab/demo/)
- `python -m week11.lab.demo_guide`로 최신 실제 실행 URL을 모은 로컬 `reports/langfuse/instructor-console.html` 생성.


전체화면 발표는 하단 **전체 화면** 버튼 또는 **P**로 시작합니다. 메뉴는 자동으로 숨겨지며 포인터를 위·아래 가장자리로 옮기면 다시 나타납니다. **Esc/P**로 종료합니다. 16:9가 아닌 화면의 여백은 비율 유지용입니다. 최신 배포 이후 기존 탭은 새로고침합니다.


## 반복해서 구분할 개념

- Trace는 요청 전체, Span은 내부 작업 구간. Langfuse는 작업을 Observation으로 기록하고 모델 호출은 Generation으로 구분합니다.
- Scores는 코드·모델·사람의 평가 기록입니다. 인용 검사 통과가 의미 정확성을 보장하지 않습니다.
- A는 기준선, B는 프롬프트 변경, C는 B에 지원 기능 확인을 추가한 변경입니다. C의 재고 경로는 실제 정책 응답이며 모델 미호출입니다.
- HOLD는 자동 조건 실패 또는 실행 불완전으로 보류, REVIEW는 조건 통과 후 사람 검토 대기입니다. 둘 다 배포 승인이 아닙니다. 수업의 Python 정책이 만든 결과이며 Langfuse 내장 승인 상태가 아닙니다.
- 09 셀 7의 REVIEW 변수는 사람 평가값을 담습니다. 10번의 REVIEW 상태와 구분합니다.

각 장표의 노트는 핵심 메시지, 설명 예시, 화면 짚기, 확인 질문, 기대 답변, 오해 방지, 다음 연결로 구성됩니다.

## 학생 화면과 발표자 노트의 분리

1. [HTML 강의안](https://smilesjcha.github.io/llmops-16week/week11/lecture/)을 Chrome 또는 Edge의 새 창에서 엽니다.
2. 하단 **발표자 모드**를 누릅니다. 교수용 노트 창이 열리고 ‘강의 창과 동기화 중’ 표시를 확인합니다.
3. 노트 창은 공유하지 않는 모니터 또는 별도 창에 둡니다. 강의 창에서 **전체 화면 / P**를 누릅니다.
4. 온라인 수업의 화면 공유 대상으로 **강의 창만** 선택합니다. 전체 데스크톱을 공유하면 교수용 노트도 보일 수 있습니다.
5. 어느 창에서든 장표를 넘기면 페이지·설명 노트·다음 장표 제목이 함께 갱신됩니다. 교수용 창에서 번호·목차 이동과 도식 단계 진행도 가능합니다.
6. 종료할 때 교수용 창의 **발표자 모드 종료** 또는 강의 창의 **모드 종료**를 누릅니다.

발표자 모드 중에는 강의 창의 화면 위 노트를 잠급니다. N을 눌러도 별도 발표자 창을 열며, 노트 창을 닫아도 강의 화면에 설명이 나타나지 않습니다. 팝업이 차단되면 이 사이트에서 허용한 뒤 **발표자 창**을 다시 누르세요. 같은 창을 새로고침하면 현재 장표로 다시 연결되고, 강의 창이 닫히면 노트 창의 연결 상태와 조작 버튼이 바뀝니다.

발표자 모드 밖에서 N을 누르면 기존 화면 위 노트가 열립니다. 수업에서는 발표자 모드를 먼저 켜고 공유하세요. GitHub Pages 또는 저장소 전체를 내려받은 로컬 환경에서 사용합니다. `index.html`만 단독 복사하면 별도 발표자 창 파일도 함께 필요합니다.


## 현재·다음 장표 미리보기와 노트 가독성

- 발표자 창 왼쪽에 현재 장표와 다음 장표가 표시됩니다. 현재 도식의 강조 단계와 지표 조작 결과도 반영됩니다.
- 각 미리보기의 **확대**를 누르면 큰 화면으로 확인합니다. **닫기 / Esc**로 돌아옵니다. 미리보기를 확대해도 학생용 장표는 넘어가지 않습니다.
- 오른쪽 설명 노트의 **A− / A+** 또는 슬라이더로 **16–36px** 사이에서 조절합니다. **기본**은 **22px**입니다.
- 크기 설정은 같은 브라우저에서 다음 실행에도 유지됩니다. 페이지 이동이나 연결 확인 때문에 기본 크기로 돌아가지 않습니다.
- 노트 영역을 따로 스크롤할 수 있습니다. 새 장표에서는 해당 노트의 처음으로 이동하며, 같은 장표를 읽는 동안에는 위치가 유지됩니다.
- 마지막 장표에서는 다음 미리보기 대신 **마지막 장표입니다**를 표시합니다.

수업 전에는 기존 강의 창을 새로고침한 뒤 발표자 창을 다시 여세요. 작은 글자가 있는 도식·제품 화면은 확대 미리보기로 확인하고, 실제 설명은 본인 화면 크기에 맞춘 노트 글씨 크기로 진행합니다.
