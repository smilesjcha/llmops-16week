# 11주차 100분 진행안

## 수업 전 준비

1. Python 3.11 / `requirements/week11-offline.txt` 확인.
2. Ollama 앱 실행, `ollama pull qwen2.5:1.5b-instruct` 완료. 서버가 이미 실행 중이면 추가로 `ollama serve`를 띄우지 않습니다.
3. `python -m week11.lab.ollama_lab --limit 3 --judge`를 실행해 로딩·응답을 확인합니다.
4. HTML 16쪽 지표 조작, 40쪽 그림 확대, 단계별 목차 이동 확인.
5. [파일별 실행 순서·정상 결과](../lab/WALKTHROUGH.md)를 열어 학생 화면과 비교합니다.

[HTML 강의안](https://smilesjcha.github.io/llmops-16week/week11/lecture/), [검색 평가 보고서](https://smilesjcha.github.io/llmops-16week/week11/lab/sample/report.html), [실제 Ollama 실행 예제](https://smilesjcha.github.io/llmops-16week/week11/lab/sample/ollama/ollama-report.html)는 다운로드 없이 볼 수 있습니다.

## 설명보다 관찰을 먼저 요청할 지점

- 5쪽: 참고 정답을 생성 모델에 주면 어떤 문제가 생기는가?
- 16쪽: k=3에서 4로 바뀔 때 Recall과 MRR 중 무엇이 변하는가?
- 24쪽: 평균이 좋아져도 구어체 질문의 사용성은 어떠한가?
- 30쪽: 확인 불가라는 문장과 `abstain`·인용 값이 일치하는가?
- 36쪽: 작은 평가 모델의 supported 판정을 그대로 믿어도 되는가?
- 40–42쪽: 08의 로컬 trace를 플랫폼에서는 어디에서 찾아볼 것인가?
- 45쪽: 검색 개선에도 HOLD인 두 가지 이유는 무엇인가?

## 실습 구분

- 01–06: 실제 검색·지표 계산. 05의 judge 표만 작성 예시입니다.
- 07–08: 실제 Ollama 생성·평가. 작은 모델은 누락·추측·판정 오류를 낼 수 있습니다. 오류를 정답으로 교체하지 않고 검토합니다.
- 실제 응답이 예제와 다르면 문장 일치를 요구하지 않습니다. 근거·조건·기권·인용을 대조합니다.
- Langfuse 화면은 공식 제품 예시, LangSmith 아키텍처는 공식 문서 기반 재구성입니다. 계정 연결이나 외부 전송을 했다고 설명하지 않습니다.
- 학생 모델 다운로드가 끝나지 않았으면 공개된 실제 실행 예제로 먼저 관찰합니다. 이것을 현장 실시간 실행으로 표현하지 않습니다.
- 새로운 과제 마감이나 배점은 추가하지 않습니다. 교수 설명 노트와 상세 실행 안내는 복습용으로 제공합니다.
