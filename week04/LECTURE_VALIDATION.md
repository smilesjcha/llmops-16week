# 4·5주차 및 프로젝트 안내 제작·검수 기록

2026년 9월 30일 기준. 공통 제작 정책은 [PPT 제작 가이드](../week01/lecture/PPT_PRODUCTION_GUIDELINE.md)를 따른다.

## 자료와 학습 범위

- 4주차 77장: RAG 구조, 문서 분할, 출처·버전·접근 범위, 검색·보류, 평가·과제.
- 5주차 80장: TF-IDF·BM25, 의미 검색의 차이, RRF, 후보 수·재정렬, 실패 질의와 프로젝트 연결.
- 8주차 제출 안내 16장: 팀·개인 구성, 자유 형식, 두괄식 작성, 사업·사용자 경험·개발 관점, 100점 평가 기준.
- 4·5주차는 각각 100분 구성. 기본 셀을 함께 실행하고 확장 실험과 모델 연결은 자율 심화로 구분한다.

## 디자인·파일 검수

- 흑백·회색·네이비·파랑만 자체 디자인에 사용. 위치나 마지막 단계라는 이유의 자동 강조를 제거했다.
- 편집 가능한 번호 도식·표·차트를 사용하고, 원 논문 도식과 실제 실습 화면을 추가했다.
- 본문 20–23pt, 표 17pt, 코드 18pt, 보조 문구·페이지 번호 14pt 이상. 긴 한글 제목은 이 자료의 그리드에 맞춘 34pt이며, 표지 54pt·구간 제목 44pt다.
- 의미 단위 개행을 작성 단계에서 지정. 자동 글자 축소를 사용하지 않는다.
- 단계 번호와 단계명의 영역 분리, 가변 카드 높이, 연결선의 측면 배치로 텍스트 겹침을 방지했다.
- 3개 PPTX의 패키지 무결성·글꼴·제목 맞춤·레이아웃·재가져오기 검사 통과. 차트의 수치와 내장 워크북 대조 검사 통과.
- 최종 PDF 77·75·16쪽을 전 페이지 렌더하여 개별 검수. 수정한 차트·도식·화면 장표는 재렌더 후 재검수.
- 차트의 비율 축은 0–100%, 길이 보정 축은 0–2로 고정. 곡선 보간으로 실제 데이터에 없는 역전을 만들지 않도록 직선 연결을 사용한다.
- 작은 화면 캡처는 원문 판독 대신 무엇을 관찰할지 알려주는 큰 보조 레이블로 보완했다. 원본 서비스와 전체 노트북은 각 실습 폴더에서 확인한다.

## 내용·실습의 일치

- 4주차 추석 녹화 대체, 6주차 한글날 강의·영상·신규 과제 없음, 7주차 실시간 수업 재개와 기획서 초안 피드백, 8주차 시험·실시간 수업 없는 수정본 온라인 제출·평가, 16주차 실시간 온라인 발표를 일치시켰다.
- 제출 형식은 자유. 2Pager·PRD·PPT를 모두 제출할 의무가 없으며, 시안·데모 영상·유료 도구는 선택이다.
- 실제 고객 자료 대신 합성 정책을 사용한다. 기본 응답은 원문 발췌이며 LLM 생성이 아니다.
- TF-IDF는 통계 기반 벡터, 재정렬은 규칙 기반임을 명시. Recall·MRR과 답변 정확도를 구분한다.
- Ollama 실습은 기본 OFF. 모델 호출 없이 기본 실행 검증이 가능하며 실제 모델 추론 성능은 검증 범위 밖이다.
- 자동 테스트와 새 커널 실행 결과는 [실습 검증 기록](LAB_TEST_REPORT.md)에 정리했다.
- 수강생 연락처·팀 신청 응답은 제한 공유 Google Sheets에만 보관한다. 공개 자료에는 빈 신청 폼 URL만 연결한다.

## HTML 검수

로드맵의 현재 주차 강조·온라인 일정, 과제의 제출 경로·마감 원칙, PRD의 편집 항목을 실제 브라우저에서 확인했다.
2Pager 편집 후 HTML 저장 파일에 변경 내용이 포함되는 것을 확인했다. 외부 CSS·폰트·스크립트 없이 열 수 있고, 작성 내용은 서버로 전송하지 않는다.
모바일 제출 안내에서 페이지 전체 가로 넘침 없이 표만 가로 스크롤되는 것을 확인했다.

제작 소스: `scripts/build_course_deck.mjs`, `scripts/course_deck_content.mjs`, `scripts/build_course_html.mjs`.
차트 재측정: `python scripts/measure_retrieval_charts.py`. 수치·시간은 작은 합성 자료의 학습 예시이며 운영 성능 보장이 아니다.
