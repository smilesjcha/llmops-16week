# AS-IS 대비 4·5주차 개선

작년 notebook의 검색 증강 생성과 검색 비교 개념은 유지하되 현재 실습 필수 경로를 분리했다.
기존 Pinecone·외부 임베딩·환경 종속 설치는 AS-IS 폴더에 보존하며 삭제하지 않았다.

| 개선 | 학습 목적 |
|---|---|
| 합성 문서18개·질의16개 | 설치 비용 없이 정책·기간·권한 실패 관찰 |
| ipynb8개·단계별 수동 계산 | 실행 버튼 외에 원리·수식·설정 직접 실험 |
| 날짜·권한 선행 필터 | 검색 이후 숨기기로 처리하지 않는 데이터 설계 |
| BM25·TF-IDF·RRF 실제 계산 | 점수·순위·규칙 재정렬의 차이 이해 |
| 개발·테스트 질의 분리 | 설정 선택과 최종 평가의 구분 |
| 검색 회수·답변 보류 별도 지표 | 검색 성공을 답변 정확도로 오해하지 않기 |
| 실제 로컬 앱·API 테스트 | 입력 오류·출처·JSON·재현성 확인 |
| 선택 Ollama | 실제 임베딩·LLM 호출을 기본 발췌 데모와 구분 |

문자 기준 chunking, 교육용 토큰화, 모의 역할 선택, 규칙 재정렬은 프로덕션 구현이 아니다.
실서비스 확장에는 인증·권한·대용량 색인·평가 데이터·모델·배포 설계가 추가로 필요하다.
