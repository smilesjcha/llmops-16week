## 실습 시작

저장소 루트를 VS Code로 연다. 1주차의 `.venv`와 고정된 `requirements.txt`를 그대로 사용한다. Python 기준은 **CPython 3.11.14**이며, 2주차를 위한 추가 패키지 설치는 없다.

macOS/Linux에서는 VS Code의 **Terminal → Run Task → Week 02: Run PROMPT/02**를 선택하거나 다음 명령을 실행한다. Windows는 아래 링크의 PowerShell 순서를 사용한다.

```bash
.venv/bin/python -m uvicorn prompt02.main:app --app-dir week02/lab --host 127.0.0.1 --port 8002
```

브라우저에서 <http://127.0.0.1:8002> 접속 → `Demo` 선택 → 동일 사례로 세 버전 비교 → 실패 상세 확인 → 버전 선택 이유 저장 → JSON 내보내기.

- 1주차 서버는 `8000`, 2주차 서버는 `8002`를 사용하므로 함께 실행할 수 있다.
- `Demo`는 비교·검증 절차를 배우는 **결정론적 시뮬레이션**이다. 실제 언어 모델 성능 측정이 아니다.
- 실제 모델은 선택 실습이다. Ollama 연결·모델 설치가 필요하며 결과·속도는 장비와 설정에 따라 달라진다. 자동으로 유료 API를 호출하지 않는다.
- 서버 메모리의 기록은 재시작하면 초기화된다. 수업 종료 전에 JSON을 내보낸다.
- 합성 고객 문의만 사용한다. 학생 이름·연락처·실제 고객 문의·비밀키를 공개 저장소에 넣지 않는다.

Windows와 새 환경 설치, `.env` 설정, Thinking 비활성화, 오류 복구는 [VS Code 실행 가이드](VS_CODE_GUIDE.md)에서 순서대로 확인한다.

## 이번 주 완료 기준

1. 입력·출력·업무 규칙을 한 문서로 설명
2. 같은 입력과 설정을 사용한 v1·v2·v3 비교 기록
3. 형식 오류와 업무 판단 오류의 구분
4. 버전 선택 또는 보류 이유, 실험의 한계
5. 3주차 평가를 위한 새 실패 사례와 교수 리뷰 질문

기록은 8주차 기말 프로젝트 기획서의 근거로 누적한다. **8주차에는 중간고사와 실시간 수업이 없으며 온라인 제출물만으로 평가**한다. 16주차 프로젝트 발표는 실시간 온라인이다. 9월 25일 추석·10월 9일 한글날 주차는 휴강이 아니라 녹화 강의영상 업로드로 대체한다.
