캡처·연구 그림 안 글꼴은 원본 래스터 이미지이며, 편집 가능한 14pt 텍스트 검사와 구분한다. 전체 화면을 축소해 넣지 않고 필요한 영역을 확대했다. 원본은 보존하고 PowerPoint 사진의 표시 영역만 지정했다. 좌표와 원본 크기는 [실습 화면](assets/captures.json), [외부 그림](assets/external/figures.json)에 기록했다. 원문 사진·차트의 색·축·범례는 근거 보존을 위해 그대로 유지한다.

외부 사진·그림은 [출처와 라이선스](EXTERNAL_VISUAL_SOURCES.md)를 확인했다. CLIP 사과 사진의 분류 점수는 정확도·신뢰도와 구분하며, 문맥 위치 실험은 당시 모델·20개 문서 조건임을 명시했다. ToT는 이번 고정 프롬프트 버전 비교와 구분하며, 원본 MIT 전문을 자산과 발표자 노트에 함께 보존했다.

## 한 장씩 시각 검수

1. 시각 자료·도식을 추가한 v6 PDF 72쪽을 1600×900 이미지로 렌더했다.
2. 1–24, 25–48, 49–72쪽을 각각 원본 크기로 전수 확인했다. 제목·본문 잘림, 어절 중간 개행, 연결선 방향, 도형·선 겹침, 표 높이, 원본 그림 범위와 캡션 간격을 점검했다.
3. 발견한 연결 화살표 역방향, 8장 출력 상자 하단 여백, 18·35·59장 설명 간격, 50장 가지선과 조건 라벨 겹침을 수정했다. 14·15·17장 중복 주석과 24장 고립 줄을 정리했다.
4. v7에서 변경된 18장(8·11·12·14·15·17·18·19·24·25·28·30·35·42·50·59·60·66)을 다시 개별 확인했다. 나머지 54쪽 렌더는 검수 완료한 v6와 바이트 단위로 같았다.
5. v8은 48장 발표자 노트의 첫 선택 사례와 21·72장 노트의 출처 경로만 정리했다. 최종 PDF 72쪽을 다시 렌더하고 모든 페이지가 검수된 v7과 바이트 단위로 같음을 확인했다. 미해결 P1/P2 시각 검수 사항은 없다.

검수 중간 렌더·자동 검증 영수증은 로컬 `build/`에 보관하고 공개 Git에는 포함하지 않는다.

## 실습과의 일치

- 실제 VS Code 실행 작업과 로컬 PROMPT/02 화면을 캡처했다. 고객 문의는 8개 합성 사례이며 학생·실제 고객 개인정보를 포함하지 않는다.
- 브라우저에서 Demo 24개 결과 비교, T03/v2 실패 상세 확인, v3 선택 근거 저장, JSON 내보내기 HTTP 200을 확인했다.
- Demo 결과는 고정 응답 재생이며 실제 언어 모델의 성능 측정이 아님을 앱·교안·장표에 명시했다.
- 이번 개정 후 저장소 테스트 64개 통과, Ruff 통과, 공통 환경 의존성 123개 호환 확인. 로컬 웹 서버에서 Demo 9건 비교·검사·결정·JSON 내보내기 smoke 재검사 통과.
- 노트북 코드 9셀은 최초 2주차 패키지 검증에서 실행 오류가 없었으며 이번 시각·안내 개정에서 실행 코드는 변경하지 않았다.
- 실제 Ollama 비교는 3개 문의 × 3개 버전의 9회 호출, 통신 오류 0. 형식 통과와 업무 판단 통과를 구분해 기록했다.
- 위 기존 실제 실행 기록을 54장 차트로 표현하고 원본 요약 데이터와 차트 값 일치 확인. 이번 개정에서 Ollama 품질 실험을 새로 실행하거나 전체 모델 성능을 검증한 것은 아니다.
- 상세 명령·설정·측정값·한계는 [실습 검증 보고서](../LAB_TEST_REPORT.md) 참고.

## 검증 범위의 한계

- macOS의 실제 실습과 PDF 출력 결과를 확인했다. Windows/Linux 및 별도 컴퓨터의 Microsoft PowerPoint 렌더링은 직접 검증하지 않았다. Windows는 [PowerShell 실행 안내](../VS_CODE_GUIDE.md)를 제공한다.
- AppleGothic·Menlo가 없는 환경에서 PowerPoint의 대체 폰트는 줄바꿈을 바꿀 수 있다. 학생에게는 검수된 PDF를 우선 배포한다.
- 자동 구조·넘침 검사는 모든 의미 오류나 디자인 문제를 보장하지 않으므로 개별 시각 검수와 병행했다.
- 이번 검증은 1·2주차 코드 범위다. 아직 구현되지 않은 3–16주차 전체 코드의 안정성을 검증했다고 주장하지 않는다.
