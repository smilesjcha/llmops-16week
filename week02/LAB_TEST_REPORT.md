## 테스트가 다루는 실패

- JSON이 아닌 문장, 코드 블록, 배열/null/NaN, 중복 키, 잘못된 자료형, 추가 필드, 공백 답변, 과도한 중첩.
- 코드처럼 보이는 출력과 지시문 주입을 데이터로 취급하며 실행하지 않는 동작.
- 형식은 맞지만 분류가 틀린 결과, 근거 없는 환불·입금·배송 약속, 확인이 필요한 경우.
- 문의별로 동일한 입력을 사용하는지, 정답 라벨이 모델 메시지에 포함되지 않는지.
- 입력·프롬프트 해시의 안정성, 변경 민감도, 선택 입력 세트와 전체 데이터의 해시 분리.
- 실험 중 버전별 템플릿을 한 번만 읽어 일관된 스냅샷을 사용하는지.
- Ollama 404/429/500/503/302, 연결 실패, 시간 초과, 빈 응답, 손상된 응답·메타데이터.
- 오류가 나면 demo로 자동 전환하지 않고 나머지 요청을 미실행으로 기록하는지.
- 로컬 외 주소 거부, 허용하지 않은 요청·버전·문의 거부.
- 실험에서 확인한 버전만 후보로 기록하며 `deployed:false`를 유지하는지.

## 적용 범위

정규표현식 기반 확정 약속 검사는 오탐·미탐이 가능한 제한된 교육용 검사입니다. 이 테스트는 모든 자연어 사실 오류, 프롬프트 주입 공격, 한국어 품질, 실제 기업 정책을 검증하지 않습니다. 8건의 공개 합성 데이터로 실제 운영 채택이나 보안 완전성을 판단하지 않습니다.

필수 실습의 재현성과 오류 분리는 자동 검증했고, 실제 모델 결과는 별도 관찰로 구분합니다. 보고서 파일에는 합성 문의와 교육용 결정만 저장하며 개인정보 입력을 요구하지 않습니다.
