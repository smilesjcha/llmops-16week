## 권장 복습 순서

1. [학생용 2주차 PDF](../../output/pdf/02_week2_prompt_design_versioning.pdf)에서 수업 흐름을 확인한다.
2. 강의 영상에서 프롬프트 v1·v2·v3 비교와 실패 사례 설명을 본다.
3. [PROMPT/02 실습 안내](../lab/README.md)와 [VS Code 실행 가이드](../VS_CODE_GUIDE.md)를 따라 같은 비교를 재현한다.
4. 영상의 안내와 현재 PDF가 다르면 현재 `main` 브랜치의 PDF·실습 코드·수업 공지를 우선한다.

Google Drive 파일의 재생·다운로드 가능 여부는 해당 파일의 공유 권한을 따른다. 수강생 과제, 실제 고객 정보, API 키는 공개 GitHub나 복습 자료에 올리지 않는다.
