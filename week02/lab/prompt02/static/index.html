PROMPT/02

고객 문의 분류부터 답변 검증까지.
프롬프트 변경의 근거를 기록하는 실험 작업대.

오늘의 실험
  1. 규칙과 출력 형식의 명시
  2. 경계 사례를 위한 소수 예시
  3. 동일 조건 비교와 변경 근거
교육용 시뮬레이션 고정 응답을 재생합니다. 실제 모델의 성능 측정이 아니며, 프롬프트를 수정해도 demo 응답은 바뀌지 않습니다.

STEP 01

실험 설정

합성 문의 · 실제 고객 정보 없음

API 키와 모델 설치 없이 모든 필수 실습을 진행할 수 있습니다.

동일한 입력 세트

8건 선택

선택한 각 문의를 v1 · v2 · v3에 동일하게 전달합니다.
평가 정답은 모델 메시지에 포함하지 않습니다.
