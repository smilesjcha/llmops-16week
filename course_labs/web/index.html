검색 실험실

문서 · 검색 순위 · 출처 · 평가 결과
교육용 합성 정책 18개 · 모델 다운로드와 API 키 불필요 · 응답은 검색 원문 발췌이며 LLM 생성이 아닙니다.

01 검색 설정

TF-IDF는 학습된 임베딩이 아닙니다. 규칙 재정렬은 신경망 reranker가 아닙니다. 역할 선택은 수업용 모의 설정이며 인증 기능이 아닙니다.

02 근거와 결과

검색 후 문서 ID·버전·원문 위치를 확인합니다.

03 관찰 기록

한 번에 설정 하나만 변경합니다. 어떤 질의의 근거와 순위가 달라졌는지 설명합니다.

평가는 정답 문서 ID를 기준으로 합니다. 답이 없는 질의는 Recall·MRR 평균에서 제외하고 보류 여부를 따로 집계합니다.
